# Little Wings — AI Consistency Rules

## Canon Is Authoritative
AI creativity is allowed only inside established canon.

## Character Lock
Always use the correct character ID and approved reference.

Do not alter:
- face
- hair
- clothing
- accessories
- age appearance
- body proportions

unless explicitly authorized.

## Environment Lock
Use the approved environment reference whenever available.

## Reference Reuse
Do not create a new reference image for every scene when an approved master reference can cover the required character/location combination.

## Reference Priority
1. Approved master reference
2. Approved episode reference
3. New generation only when no suitable approved reference exists

## New Reference Rule
A new reference must not become canon automatically. It must be reviewed and approved.

## Conflict Resolution
If a generated result conflicts with canon, regenerate/correct it. Do not redefine canon to match the incorrect output.

## Prompt Rule
Every production prompt should carry the relevant character IDs, environment ID, reference requirement, visual constraints, action, camera, dialogue, and lip-sync rule.
