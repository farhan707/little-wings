# Little Wings — Series Production Bible

## Status
- Canon status: ACTIVE
- Bible version: 1.0
- Purpose: Single source of truth for the Little Wings universe and production system.

## Core Principle
The Series Bible is the single source of truth for Little Wings.

AI may create new story content inside the established universe, but it must not silently change established characters, relationships, environments, visual identity, language rules, or production rules.

## Production Pipeline
Story → Story Analysis → Character Identification → Location Identification → Master Reference Selection → Scene Breakdown → Dialogue Assignment → Action Assignment → Camera Assignment → Character Lock → Environment Lock → Lip-Sync Lock → Video Prompt Generation → QA

## Canon Priority
1. Explicitly approved Series Bible rules
2. Approved character/environment master references
3. Approved episode-specific canon
4. Approved production rules
5. New AI creative suggestions

Consistency wins over unnecessary creativity.

## Canon Change Rule
A generated image, video, prompt, or temporary creative decision does not automatically become canon.

Canon changes require an explicit update to the Series Bible and a version change.

## Automation Goal
Future automation should accept a story as the primary input and derive the production plan without requiring the universe to be redefined for every episode.

Required outputs:
- characters
- locations
- required references
- scene/clip breakdown
- dialogue
- actions
- camera
- visual prompts
- lip-sync constraints
- QA checklist
