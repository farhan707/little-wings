# Little Wings — Quality Control

## Mandatory QA Categories

### 1. Character
- correct character IDs
- correct face
- correct hair
- correct clothing
- correct accessories
- correct age appearance

### 2. Environment
- correct location
- correct layout
- correct furniture
- correct major props
- consistent lighting

### 3. Dialogue
- exact dialogue
- correct speaker
- natural timing
- no wrong-character speech

### 4. Lip-Sync
- only active speaker moves lips
- silent mouths remain closed
- dialogue matches visible speaker

### 5. Motion
- natural body movement
- no broken anatomy
- no unwanted object movement
- no excessive camera motion

### 6. Continuity
- previous and next clips connect logically
- clothing remains consistent
- props remain consistent
- emotional state is plausible

### 7. Canon
- no unauthorized character redesign
- no unauthorized environment redesign
- no accidental canon change

## QA Status
Each clip should be marked:
- PASS
- REGENERATE
- NEEDS_REVIEW

## Golden Rule
Never accept an attractive clip that violates established canon.
