# Little Wings — Environment Assets

Every recurring environment receives a stable Environment ID.

## Candidate Core Locations
- `ENV_KITCHEN_001`
- `ENV_DINING_001`
- `ENV_LIVING_001`
- `ENV_BEDROOM_001`
- `ENV_GARDEN_001`
- `ENV_SCHOOL_001`

A candidate environment is not canon until its master reference is approved.

## Continuity
Lock layout, major furniture, windows/doors, recurring props, lighting direction, and time-of-day appearance for approved recurring locations.
