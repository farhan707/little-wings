# Little Wings — Character Assets

Character folders are organized by immutable Character ID.

## Rules
- Every recurring character has one canonical ID.
- Master reference assets are approved identity sources.
- Generated episode assets do not automatically become master canon.
- Do not replace a master reference without an explicit canon update.
